# Levantamento das centrais · 08/10/2026

O utilizador confirma Siemens FC726 nas quatro centrais: SADI 1 (Guarita Social 2), SADI 2 (Salão de Festas), SADI 3 (Guarita Social 1) e SADI 4 (Guarita de Serviço).

As 11 fotografias e o vídeo recebidos são do levantamento da Guarita de Serviço, identificada documentalmente como SADI 4. A etiqueta patrimonial CDI / Fire Detection / Equipamento Nº3 / Critical não identifica a central como SADI 3.

Referências transcritas das fotografias:

- Placa técnica Siemens FC726; etiqueta frontal FS726.
- Fonte SV 24V-150W, referência V24230-Z6-A5.
- Etiqueta FCM7204-Z3, artigo A5Q00037625 02.
- Placa FCM2027, referência A5Q00031466-04.
- Conectores e posições marcadas: X5, PER.-BUS, Network Module Pos.1, Pos.2 (Degrade), SER OPT1 / OPT2, MASTER-LCD / SLAVE-LCD.

Não se extrapola a composição interna para as outras centrais. A cablagem é evidência visual; destinos, ocupação dos circuitos e endereços precisam de conferência. AVARIA e ISOLADOS iluminados constituem uma observação fotográfica, não o estado actual nem diagnóstico técnico. Não foram criadas ocorrências reais com base nestas imagens.

O vídeo está disponível no site como anexo; a transcrição técnica acima deriva das fotografias.

## Dados necessários para integração

Recolher versão de firmware, exportação da configuração, inventário dos módulos efectivamente instalados, interface suportada, protocolo, licenças e correspondência ponto → central/loop → casa actual → piso/local. Manter separadas a identificação patrimonial e a identificação documental.
